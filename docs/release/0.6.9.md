# MGD KI-Bildkennzeichnung 0.6.9

## Sicherheits-Härtung und vollständige Dokumentation

Version 0.6.9 schärft die Update-Prüfung und vervollständigt die öffentliche
Dokumentation.

### Geändert

- Ein GitHub-Update wird nur noch akzeptiert, wenn das Paket über HTTPS ohne
  Sonderport aus dem festen Release-Pfad von
  `MichaelGahnDESIGN/MGD-AI-Image-Labels` stammt.
- Regressionstests verhindern, dass ein fremdes GitHub-Repository oder ein
  abweichender Port künftig als Update-Quelle durchrutscht.
- README, SECURITY.md, CONTRIBUTING.md und das GitHub-Wiki beschreiben nun
  Bedienung, Divi- und Beitragsbild-Ausgabe, Medienvorschau, Update-Prozess,
  Fehlersuche, Architektur, Datenschutz und Prüfumfang.

### Upgrade

Vor dem Update ein getestetes Backup erstellen. Danach in der Mediathek einen
gespeicherten Anhang sowie im Frontend mindestens ein Beitragsbild und eine
Blogkarte prüfen. Die gespeicherten Kennzeichnungswerte bleiben erhalten.
