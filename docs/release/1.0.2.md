# MGD AI Kennzeichnung WordPress 1.0.2

**Übergangsrelease für die Repository-Umbenennung**

Diese Version stellt den internen GitHub-Update-Endpunkt auf das zukünftige
Repository `MichaelGahnDESIGN/MGD-AI-Kennzeichnung-WordPress` um. Der
technische Plugin-Ordner, der WordPress-Slug und alle gespeicherten
Kennzeichnungswerte bleiben unverändert.

## Wichtig für bestehende Installationen

1. Version 1.0.2 noch wie gewohnt aus dem bisherigen Repository aktualisieren.
2. Erst nachdem die verwalteten WordPress-Installationen 1.0.2 verwenden, wird
   das GitHub-Repository umbenannt.
3. Künftige Updates kommen anschließend wieder normal über WordPress.

Die Version enthält keine Datenmigration und löscht oder verändert keine
Bilddateien, Kennzeichnungen oder Einstellungen.
