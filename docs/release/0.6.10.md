# MGD KI-Bildkennzeichnung 0.6.10

## Stabiler Frontend-Fallback für mehrere Kennzeichnungen

Diese Version behebt einen Fehler im lokalen Frontend-Fallback. Er konnte bei
mehreren gekennzeichneten Bildern auf einer Seite zu wiederholten DOM-Änderungen
führen. Davon waren insbesondere Divi-Blogmodule, Beitragsarchive und Seiten
mit mehreren gekennzeichneten Bildern betroffen.

### Behoben

- Bereits verarbeitete Bilder behalten ihren vorhandenen Kennzeichnungs-Wrapper.
- Der MutationObserver ignoriert die vom Plugin selbst ergänzten Wrapper und
  Badges.
- Mehrere Kennzeichnungen bleiben dadurch unabhängig voneinander und die
  Seitendarstellung wird nicht mehr durch eine Schleife belastet.

### Upgrade

1. Vor dem Update ein geprüftes WordPress-Backup anlegen.
2. Auf **0.6.10** aktualisieren.
3. Den Cache des Caching-Plugins beziehungsweise CDN leeren.
4. Eine Blogübersicht und eine Seite mit mehreren gekennzeichneten Bildern in
   einem privaten Browserfenster prüfen.

Gespeicherte Status-, Positions- und Glaswerte bleiben vollständig erhalten.
