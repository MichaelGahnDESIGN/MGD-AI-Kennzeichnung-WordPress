# Release 1.0.10 – Icons und Hintergründe aus dem Feed

## Für Anwender

Die Karten unter „Weitere Plugins" zeigen jetzt Icons und Hintergründe von
theme.michael-gahn.de. Der Server holt jedes Bild einmal und speichert es lokal.
Der Browser lädt nichts von außen. Gibt es kein Bild, bleibt das mitgelieferte
Motiv. Versionen werden ohne führendes „v" angezeigt.
